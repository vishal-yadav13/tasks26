# React Card Component

## About Project

This project is created using React.
It shows product information using a reusable Card component.

## Features

* Created a reusable Card component
* Used props to pass data
* Displayed multiple cards using array mapping
* Added gradient border to cards
* Responsive design

## Technologies Used

* React
* JavaScript
* CSS

## How to Run

1. Open the project folder in VS Code.
2. Install packages:

```bash
npm install
```

3. Run the project:

```bash
npm run dev
```

4. Open the localhost link in the browser.
